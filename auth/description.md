# Модуль авторизации

Модуль авторизации отвечает за регистрацию и вход студентов и преподавателей. Он разграничивает уровни доступа к функциям трекера. Остальные модули используют его для проверки прав пользователя.

## Функции модуля

- Регистрация студентов и преподавателей с проверкой данных
- Вход и выход из системы, хранение сессии
- Разделение ролей: студент, преподаватель, администратор
- Проверка прав доступа для других модулей
- Восстановление пароля
